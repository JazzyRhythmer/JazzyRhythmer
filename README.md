# Jazzy Rhythmer

[![Two sides of the FM-1. Discover a sound with JAZZY. Build a groove with RHYTHMER.](https://raw.githubusercontent.com/JazzyRhythmer/Rhythmer/main/docs/github/firmware-lineup.png)](https://jazzyrhythmer.github.io/Jazzy/#companion)

I make music and instruments for finding the next groove. These are two free, open-source firmwares for the M-VAVE FM-1.

| [JAZZY](https://github.com/JazzyRhythmer/Jazzy) | [RHYTHMER](https://github.com/JazzyRhythmer/Rhythmer) |
| --- | --- |
| **Explore the unheard.** One sound per track. Browse 31 synth, drum and Break engines and over 1,200 factory sounds. | **Sound into motion.** Build grooves with assignable tracks, individual drum swaps, per-track generation and break chops. |
